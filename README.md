# LUMO

LUMO — полный e‑commerce проект электроники и товаров для дома. Фокус: mobile‑first UX, скорость, минимальные шаги до покупки и чистая архитектура.

## Стек

- Frontend: Next.js (App Router), TypeScript, Tailwind CSS
- Forms: React Hook Form, Zod
- State: TanStack Query, Zustand
- Animations: Framer Motion
- Backend (план): PostgreSQL, Prisma, Auth

## Структура

```
.
├── frontend/         # клиент (Next.js)
├── backend/          # API (заглушка)
└── README.md
```

## Запуск

```bash
cd frontend
npm install
npm run dev
```
